# 30 FUERTE Android

Proyecto Android offline para compilar automáticamente con GitHub Actions.

- App: 30 FUERTE
- Package: `com.fuerte30.app`
- WebView local, sin Internet requerido
- Guarda progreso con `localStorage`
- Voz mediante Android TextToSpeech
- El workflow `.github/workflows/build-apk.yml` genera `app-debug.apk`
